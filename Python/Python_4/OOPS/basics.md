OOPS -> Object Oriented Programming.
It is a way of writing programs by organizing code around objects.

Simple example

Think of a Car:

Properties (data): color, brand, speed
Functions (behavior): drive(), brake(), accelerate()

It has class and object

CLASS - Its blueprint of an object and is made once

Class has two things :
1.) Properties/Attributes
2.) Behaviours/methods


OBJECT - Instance of class and takes the memory
