# 4 Pillars of OOP

## 1. Encapsulation 🔒

**Definition:** Wrapping data and methods together inside a class and controlling access to the data.

**Real-life example:** Bank account — your balance is protected, and you change it through `deposit()` or `withdraw()`.

---

## 2. Abstraction 🎛️

**Definition:** Hiding unnecessary implementation details and showing only what is needed.

**Real-life example:** Car — you use the steering wheel, brake, and accelerator without knowing how the engine works internally.

---

## 3. Inheritance 👨‍👦

**Definition:** A child class can acquire properties and methods from a parent class.

**Real-life example:** Dog is an Animal. A dog can inherit common features like `eat()` and `sleep()` from Animal.

---

## 4. Polymorphism 🔄

**Definition:** The same method or action can behave differently for different objects.

**Real-life example:** `make_sound()` behaves differently:
- Dog → Bark
- Cat → Meow
- Cow → Moo

---

### Easy way to remember

- **Encapsulation** → Protect
- **Abstraction** → Hide
- **Inheritance** → Reuse
- **Polymorphism** → Different behavior
